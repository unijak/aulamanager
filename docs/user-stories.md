User Stories

US01 – Criar Turma

Como professor,

quero criar uma turma,

para organizar meus estudantes em um ambiente virtual de aprendizagem.

Critérios de Aceitação

* Apenas professores podem criar turmas.
* O nome da turma é obrigatório.
* O sistema deve gerar um código único para a turma.

⸻

US02 – Ingressar em Turma

Como estudante,

quero ingressar em uma turma utilizando um código de acesso,

para participar das atividades e missões disponibilizadas pelo professor.

Critérios de Aceitação

* O estudante deve informar um código válido.
* Apenas estudantes matriculados podem acessar os conteúdos da turma.
* O sistema deve confirmar a matrícula na turma.

⸻

US03 – Criar Atividade

Como professor,

quero criar atividades para minha turma,

para avaliar o aprendizado dos estudantes.

Critérios de Aceitação

* Apenas professores podem criar atividades.
* Toda atividade deve possuir título e descrição.
* Toda atividade deve possuir uma data limite para entrega.

⸻

US04 – Visualizar Atividades

Como estudante,

quero visualizar as atividades disponíveis,

para acompanhar minhas responsabilidades acadêmicas.

Critérios de Aceitação

* O sistema deve listar as atividades da turma.
* O sistema deve exibir os prazos de entrega.
* O estudante deve visualizar apenas atividades de turmas em que está matriculado.

⸻

US05 – Entregar Atividade

Como estudante,

quero enviar minhas atividades pelo sistema,

para que sejam avaliadas pelo professor.

Critérios de Aceitação

* O envio deve ocorrer dentro do prazo estabelecido.
* O sistema deve registrar a data da entrega.
* O sistema deve confirmar o envio realizado.

⸻

US06 – Corrigir Atividade

Como professor,

quero corrigir as atividades entregues,

para atribuir notas e fornecer feedback aos estudantes.

Critérios de Aceitação

* Apenas professores podem atribuir notas.
* A nota deve ser registrada no sistema.
* O professor pode adicionar comentários sobre a avaliação.

⸻

US07 – Criar Missão de Aprendizagem

Como professor,

quero criar uma missão composta por atividades relacionadas,

para organizar o processo de aprendizagem em etapas.

Critérios de Aceitação

* A missão deve possuir nome e descrição.
* A missão deve conter pelo menos uma atividade.
* O professor pode associar várias atividades à mesma missão.

⸻

US08 – Acompanhar Progresso da Missão

Como estudante,

quero visualizar meu progresso em cada missão,

para acompanhar minha evolução no conteúdo estudado.

Critérios de Aceitação

* O sistema deve exibir o percentual de conclusão da missão.
* O progresso deve ser atualizado automaticamente após a conclusão das atividades.
* O estudante deve visualizar quais etapas já foram concluídas e quais ainda estão pendentes.
